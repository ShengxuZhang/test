# ScreenControl — 局域网投屏遥控

通过局域网用平板实时观看手机屏幕，并在平板上直接触控操作手机。

- **观看**：手机端通过 MediaProjection 采集屏幕，MediaCodec 硬编码 H.264，TCP 推流；平板端硬解码渲染。
- **触控**：平板上的点击 / 长按 / 滑动会换算为归一化坐标发送到手机，由无障碍服务（AccessibilityService）注入手势，无需 Root。
- **发现**：支持 NSD/mDNS 自动搜索局域网内的被控端，也可手动输入 IP。
- **安全**：连接需输入控制密码（默认 `123456`），仅限同一局域网使用。

## 构建要求

- Android Studio（含 JDK 17）
- 两台 Android 8.0+ 设备（一台手机、一台平板），连接同一 Wi-Fi

用 Android Studio 打开项目根目录，等待 Gradle Sync 完成后，分别安装到两台设备：

```
Run ▶ app   （或 ./gradlew assembleDebug，APK 位于 app/build/outputs/apk/）
```

## 使用步骤

### 手机端（被控）
1. 打开 App，选择「手机端：投出屏幕并被控制」；
2. 点击「前往开启无障碍服务」，在系统设置中启用本应用的无障碍服务（触控注入必需）；
3. 设置控制密码，点击「开始投屏」，在系统弹窗中允许录屏；
4. 页面会显示本机 IP（端口固定 `4747`），保持 App 在前台即可。

### 平板端（控制）
1. 打开 App，选择「平板端：观看并控制对方」；
2. 输入手机显示的 IP 和密码（或点「搜索局域网设备」自动填充），点击「连接」；
3. 连接成功后即可看到手机实时画面，直接在画面上点击、长按、滑动；
4. 顶部按钮可发送「返回 / 主页 / 多任务」，右侧「断开」结束会话。

## 技术说明

| 模块 | 实现 |
| --- | --- |
| 视频采集 | `MediaProjection` + `VirtualDisplay`（最长边 1280，按屏幕等比缩放） |
| 编码/解码 | `MediaCodec` H.264 硬编硬解，8 Mbps / 30 fps，I 帧间隔 1s |
| 传输 | TCP 直连（端口 4747），自定义帧协议：`[长度][类型][载荷]`，帧满丢旧帧保实时 |
| 发现 | `NsdManager` 注册/搜索 `_screenctl._tcp.` 服务 |
| 触控注入 | `AccessibilityService#dispatchGesture` + `StrokeDescription` 连续描边（点击/滑动/长按/悬停心跳） |
| 前台服务 | `mediaProjection` 类型前台服务，带常驻通知 |

### 帧协议

```
[4 字节长度(大端)][1 字节类型][载荷]
  类型 1 = JSON（auth 握手 / hello / touch / key）
  类型 2 = 视频：[8 字节 ptsUs][4 字节 flags][H.264 数据]
```

触控坐标为归一化 0~1，两端按各自分辨率映射，天然适配不同尺寸屏幕。

## 已知限制

- 不传输音频；暂不支持双指捏合（仅单指手势）；
- 无障碍服务被系统杀掉后需重新开启；
- 手机旋转屏幕时画面按固定分辨率等比缩放（留黑边）；
- 延迟取决于网络与设备编解码性能，一般局域网内约 100~200ms；
- 未做加密，请仅在可信局域网内使用。

## 常见问题

- **能看画面但不能触控**：手机端无障碍服务未开启，到系统「设置 → 无障碍」中启用本应用。
- **搜索不到设备**：部分路由器隔离了 mDNS，直接输入 IP 即可；确认两台设备在同一网段。
- **连接失败**：检查 IP、密码，确认手机端「开始投屏」处于运行状态（通知栏有常驻通知）。
